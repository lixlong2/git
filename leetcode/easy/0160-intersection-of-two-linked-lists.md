# 160. 相交链表

题目链接：https://leetcode.cn/problems/intersection-of-two-linked-lists/

难度：Easy

标签：链表、双指针、长度差、指针对齐

## 题目内容

给定两个单链表的头节点，判断它们是否相交。

如果两个链表相交，需要返回它们开始相交的那个节点；如果不相交，返回空。

这里的“相交”不是指节点的值相同，而是指两个链表从某个节点开始，后面共用同一批节点。

## 核心观察

两个链表如果相交，那么从相交点开始，后面的部分一定完全一样。

例如：

```text
A: a1 -> a2 -> c1 -> c2 -> c3
B: b1 -> b2 -> b3 -> b4 -> c1 -> c2 -> c3
```

它们真正相交的地方是 `c1`。

从 `c1` 开始，后面都是同一段链表：

```text
c1 -> c2 -> c3
```

问题不在相交之后，而在相交之前。

两个链表前面独有部分的长度可能不同，所以两个指针如果直接从各自头节点同时出发，可能无法同时走到相交点。

## 为什么会想到统计长度

这题的关键问题是：

```text
两个指针同时走，为什么对不上？
```

原因是：

```text
它们到相交点之前的距离不同。
```

既然距离不同，就要想办法让两个指针站到“距离相交点一样远”的位置。

怎么做到这一点？

先统计两个链表的长度，算出长度差。然后让较长的链表先走这个长度差。

例如：

```text
A 长度是 5
B 长度是 7
```

B 比 A 长 2。

那么就让 B 的指针先走 2 步。

这样之后，A 指针和 B 指针距离链表尾部的长度就一样了。如果两个链表真的相交，它们继续同时往后走，就一定会在相交点相遇。

所以统计长度的目的不是单纯为了知道链表有多长，而是为了：

```text
消除两个链表起点到相交点之前的长度差。
```

## 思路总结

可以把这类题记成一句话：

```text
如果两个链表最终共享同一段尾巴，但开头长度不同，就先对齐长度。
```

具体思路是：

- 先分别统计两个链表的长度。
- 算出两个链表的长度差。
- 让较长的链表先走长度差。
- 然后两个指针一起往后走。
- 如果两个指针指向同一个节点，说明找到相交点。
- 如果走到最后都没有相同节点，说明两个链表不相交。

## 复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`

## 复盘

- 链表相交看的是“节点是否相同”，不是“节点值是否相同”。
- 单链表不能往回走，所以要想办法让两个指针从可比较的位置开始向后走。
- 统计长度是为了让两个链表的指针对齐，不是为了单纯得到长度。
- 遇到“两个链表有共同尾部，但前面长度不同”的问题，可以优先想到长度差。
