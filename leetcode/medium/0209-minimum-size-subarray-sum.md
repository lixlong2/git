# 209. 长度最小的子数组

题目链接：https://leetcode.cn/problems/minimum-size-subarray-sum/

难度：Medium

标签：数组、滑动窗口、前缀和

## 题目内容

给定一个含有 `n` 个正整数的数组 `nums` 和一个正整数 `target`。

找出该数组中满足和大于等于 `target` 的长度最小的连续子数组，并返回它的长度。如果不存在符合条件的子数组，返回 `0`。

## 第一次思路：从二维数组转向一维数组

这是我第一次遇到“内存限制”的题。

一开始容易想到记录所有子数组的和，但如果用二维数组保存每个区间的和，空间会很大。

后来想到可以用一维数组 `data` 滚动更新：

- `data[i]` 表示从下标 `i` 开始、当前长度为 `le` 的子数组和。
- 当长度从 `le - 1` 增加到 `le` 时，只需要加上新进入的那个元素。
- 这样不用保存所有区间，只保存当前这一轮长度对应的区间和。

这一步是从二维空间优化到一维空间，是很重要的进步。

## 第一次代码：一维滚动数组

```python
class Solution(object):
    def minSubArrayLen(self, target, nums):
        """
        :type target: int
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        data = [0] * n

        for le in range(1, n + 1):
            for i in range(n - le + 1):
                data[i] = data[i] + nums[i + le - 1]

                if data[i] >= target:
                    return le

        return 0
```

## 第一次复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(n)`

## 为什么内存降了，但时间还是长？

这份代码已经解决了一部分问题：空间从可能的 `O(n^2)` 降到了 `O(n)`。

但时间没有降下来，因为仍然在枚举：

```text
每一种子数组长度 le
每一种起点 i
```

循环次数大约是：

```text
n + (n - 1) + (n - 2) + ... + 1
= n * (n + 1) / 2
```

所以时间复杂度还是 `O(n^2)`。

也就是说：

```text
一维 data 解决的是内存问题。
滑动窗口解决的是时间问题。
```

LeetCode 上运行 40ms，而别人可能是 10ms，除了平台波动之外，更核心的原因是算法层面还没有把每个元素的访问次数降到常数级。

## 第二次思路：滑动窗口

这题可以用滑动窗口，是因为 `nums` 里面全是正整数。

正整数有一个很关键的性质：

```text
窗口右边加入新元素，sum 一定变大。
窗口左边移出旧元素，sum 一定变小。
```

所以可以维护一个连续窗口：

- `right` 不断往右扩，让窗口和变大。
- 一旦 `total >= target`，说明当前窗口满足条件。
- 然后移动 `left`，尝试缩短窗口。
- 每次满足条件时更新最小长度。

## 第二次代码：滑动窗口

```python
class Solution(object):
    def minSubArrayLen(self, target, nums):
        """
        :type target: int
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        left = 0
        total = 0
        ans = n + 1

        for right in range(n):
            total += nums[right]

            while total >= target:
                ans = min(ans, right - left + 1)
                total -= nums[left]
                left += 1

        if ans == n + 1:
            return 0

        return ans
```

## 第二次复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

虽然代码里有 `for` 和 `while`，但它不是 `O(n^2)`。

原因是：

```text
right 最多从左到右走 n 次。
left 最多也从左到右走 n 次。
```

每个元素最多被加入窗口一次，也最多被移出窗口一次。

## 复盘

这题我的第一版代码不是完全没有价值。

它说明我已经意识到：

```text
不能把所有区间结果都存下来。
可以用滚动方式减少空间。
```

但下一步要继续观察题目的性质：

```text
数组元素都是正整数。
连续子数组。
求满足条件的最短长度。
```

这三个信息合在一起，就应该想到滑动窗口。

以后遇到类似题目，可以提醒自己：

- 看到“连续子数组”，先想窗口。
- 看到“正整数数组 + 子数组和”，优先想滑动窗口。
- 如果窗口和太小，就移动右边界扩大。
- 如果窗口和已经满足条件，就移动左边界缩小。
- 不要只优化内存，还要问每个元素会被处理几次。

## 边界检查

- 空数组：如果 `nums = []`，返回 `0`。
- 没有任何子数组满足：最后 `ans` 仍然是 `n + 1`，返回 `0`。
- 单个元素就满足：`while total >= target` 会更新长度为 `1`。
- 整个数组才满足：窗口会一直扩大到最后。
- 多个窗口都满足：每次满足时都尝试收缩，保留最小长度。

## 记忆口诀

```text
正数数组求连续和，
右边扩张让和变大，
左边收缩让长度变短。
```
