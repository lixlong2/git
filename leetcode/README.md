# LeetCode 刷题记录

这里记录 LeetCode 题解、代码实现和复盘。

## 分类

```text
easy/      简单题
medium/    中等题
hard/      困难题
```

## 建议文件命名

```text
0001-two-sum.md
0001-two-sum.cpp
0001-two-sum.py
```

如果一道题有多种写法，可以在同一个 Markdown 里记录思路，也可以单独放不同语言的代码文件。
