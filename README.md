# 算法学习与 LeetCode 刷题记录

这个仓库用来长期记录我的算法学习、数据结构实现、LeetCode 刷题代码和学习笔记。

目标不是一开始就写得多完美，而是持续积累：每一次提交都留下一点学习痕迹，之后回头看可以看到自己的进步曲线。

## 目录结构

```text
leetcode/      LeetCode 题解、代码和复盘
algorithms/    数据结构与算法专题实现
notes/         课程、书籍、视频课等学习笔记
```

## 记录习惯

- 每道题尽量记录：题目链接、思路、复杂度、踩坑点。
- 代码可以先追求写出来，再慢慢优化表达和边界处理。
- 每次学习后用 Git 提交，提交信息尽量写清楚做了什么。
- 遇到经典题或没完全掌握的题，在 README 或笔记里标记，方便之后复习。

## 推荐提交信息

```text
add: solve two sum
add: implement linked list
note: add binary search notes
refactor: optimize merge sort
review: revisit dynamic programming basics
```
