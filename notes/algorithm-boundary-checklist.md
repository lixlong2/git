# 算法题边界处理清单

很多简单题耗时间，不一定是算法方向错了，而是边界条件和验证习惯还没有形成肌肉记忆。

以后写题时，可以把这份清单当成提交前检查表。

## 1. 先问：谁可能越界？

只要代码里出现这些访问方式，就要马上警觉：

```python
nums[i]
nums[j]
nums[i + 1]
nums[k - 1]
```

然后问自己：

```text
i 有没有可能等于 len(nums)？
j 有没有可能变成 -1？
i + 1 有没有可能超过最后一个下标？
k - 1 在 k = 0 时会不会出问题？
```

比如第 977 题里：

```python
if nums[k] <= nums[j]:
```

这里就要检查：

```text
k 会不会变成 -1？
j 会不会变成 n？
```

很多错误不是算法错，而是数组下标没有活到最后。

## 2. 每个 while 都要说清楚“不变量”

写 `while` 前，先用一句话说明循环中一直成立的事情。

比如左右双指针：

```python
while left <= right:
```

不变量可以是：

```text
left 到 right 是还没有处理的区域。
result[pos + 1:] 是已经处理好的有序区域。
```

比如快慢指针：

```python
k = 0
for i in range(len(nums)):
```

不变量可以是：

```text
nums[0:k] 永远是不等于 val 的有效元素。
```

如果说不出这个不变量，代码就很容易靠感觉修补，越修越乱。

## 3. 自己造 6 类测试

不要只跑题目给的样例。数组题至少自己测这些：

```text
空数组
长度为 1
特殊元素在开头
特殊元素在结尾
全都是特殊情况
完全没有特殊情况
```

第 27 题“移除元素”可以测：

```python
nums = []
nums = [3]; val = 3
nums = [2]; val = 3
nums = [3, 3, 3]; val = 3
nums = [1, 2, 3]; val = 3
nums = [3, 1, 2, 3]; val = 3
```

第 977 题“有序数组的平方”可以测：

```python
nums = []
nums = [-1]
nums = [0]
nums = [2]
nums = [-4, -1]
nums = [1, 3]
nums = [-4, -1, 0, 3, 10]
nums = [-7, -3, 2, 3, 11]
```

尤其要注意：

```text
全负数
全正数
有负有正有 0
```

## 4. 不要修补，先分类错误

提交失败后，不要马上加一个 `if`。

先问它属于哪一类：

```text
是空数组坏了？
是长度为 1 坏了？
是指针越界了？
是一边已经走完了？
是返回值错了？
是题目要求没看清？
```

比如第 977 题第一次代码的问题属于：

```text
归并时一边已经走完，但代码还在访问它。
```

这时候修法不是随便补一个判断，而是补完整结构：

```python
while left >= 0 and right < n:
    ...

while left >= 0:
    ...

while right < n:
    ...
```

这种叫结构性修复，比补丁稳定。

## 5. 写代码前先手推三个样例

每题写代码前，先准备三类样例：

```text
正常样例
边界样例
最容易出错样例
```

比如第 977 题：

```text
正常样例：[-4, -1, 0, 3, 10]
边界样例：[1]
最容易出错样例：[-3, -2, -1]
```

如果思路在这三个样例上都能手推过去，再开始写代码。

## 6. 小口诀

```text
空不空？
一不一？
头不头？
尾不尾？
全不全？
越不越？
```

意思是：

```text
数组会不会为空？
长度为 1 行不行？
特殊元素在开头行不行？
特殊元素在结尾行不行？
全是特殊情况行不行？
指针会不会越界？
```

## 7. 每道题复盘时加一栏

以后每道题都可以在题解里加：

```md
## 边界检查

- 空数组：
- 长度为 1：
- 全部满足：
- 全部不满足：
- 特殊值在开头：
- 特殊值在结尾：
- 指针是否可能越界：
- 返回值代表什么：
```

这栏不是为了写得好看，而是强迫自己把漏洞提前暴露出来。

## 最重要的一句话

不要急着从“能过样例”跳到“提交”。

中间加一步：

```text
我能不能自己造出让这段代码崩掉的样例？
```

能造出来，就先修。

造不出来，再提交。
